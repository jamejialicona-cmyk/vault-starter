# Ejemplo de Pagina

A knowledge page describes how something WORKS, never how the project is going.
That distinction is the one people get wrong first: progress belongs in
[[Current-State]], history belongs in the LOG.

Link densely with [[wikilinks]]. A link to a page that does not exist yet is
backlog, not an error.
